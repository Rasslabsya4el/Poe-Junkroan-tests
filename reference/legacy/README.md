# Legacy reference material

Read-only copies from v1. Nothing here is imported by v2 code, and nothing
here is a source of truth. See `docs/LEGACY.md` for what each file is and
why it was kept.

Use:

- `skill_scaling_facts.py` only to mine individual non-PoB mechanics facts
  into `src/junkroan/mechanics/notes.json` when a benchmark needs them.
- `direct_build_early_game_rails.py` only for the default numeric rails and
  ascendancy node id lists.

Do not port v1 patterns (blockers, ledgers, reports, passports) from here.
