# 2026-09-11 D24. List-type skill options are judged by PoB, not assumed

Status: Accepted

Stance (Flesh and Stone / Blood and Sand), exposure type and other list
options in PoB's "Skill Options" section are choices, not conditions: the
pipeline tries every value under the final build and keeps the one with the
best objective score in both lanes. Sand stance on the author's Cold DoT is
+22% EHP for 0 DPS; a fresh build had no stance at all before this.
