## Cloud lane: "открой lane" (#121)

Вся секция, дословно:

> Cloud session credits ($250, до 2026-11-05) — отдельный от плана кошелёк, из него платит **только** твоя cloud-сессия.
> Пока cloud lane открыт, каждая issue с меткой `pob-free` (её ставит брейн: приёмка без запуска PoB) идёт в эту
> сессию, а не локальному ORCH; PoB там нет.
>
> - Открывается **только по твоему слову** и только через брейна: скажи ему "открой lane". Брейн даёт ссылку —
>   открой её в Chrome и нажми Send (два клика). Дальше сессию кормит диспетчер, руками ничего не надо.
> - Скажи заранее, **пока лимиты плана ещё есть**: когда план кончился, брейн молчит и ссылку дать некому.
> - Закрыть: скажи брейну "закрой lane". Сам закроется в сброс недели (Thu 20:00), если сессия умерла, или когда по
>   оценке остаётся меньше $10 кредитов (считается $8 за закрытую issue от последнего чтения баланса).
> - Сессия умерла — в "Waiting on you" появится "Cloud lane: the session is gone; tell the brain if you want a new
>   one": скажи брейну, если нужна новая (те же два клика). Issue при этом вернутся локальному ORCH сами.
> - На мониторе одна строка сверху: открыт/закрыт lane, id сессии, оценка остатка $, какие issue сейчас в облаке.

## Режимы машин -- пиши брейну

Режим машины — слова брейну в чате "Brain"; он запускает одну команду и отвечает одной строкой: хост,
режим, сколько слотов занято после, какие jobs остановлены.

| ты пишешь | что запускает брейн | слотов после | идущий job |
|---|---|---|---|
| "пк под игру" | `python scripts/runs.py mode pc play --local` | 5, PoB at Idle | продолжает идти |
| "пк полностью" | `python scripts/runs.py mode pc off --local` | 0 | останавливается |
| "пк как было" | `python scripts/runs.py mode pc normal --local` | 7 днём, 10 ночью | - |
| "ноут под браузер" | `python scripts/runs.py mode laptop browser` (ssh) | 2 | продолжает идти |
| "ноут полностью" | `python scripts/runs.py mode laptop off` (с ПК; стоп на ноуте идёт по ssh) | 0 | останавливается |
| "ноут как было" | `python scripts/runs.py mode laptop normal` (ssh) | 3 | - |

Батарею ноута держит power guard (#367, #380), не брейн. Вопрос "что там?" — тоже брейну (`python scripts/runs.py status`).
